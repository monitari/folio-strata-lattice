직접 풀어 보기

모델이 실제로 받은 시험 문제다. 먼저 풀어 보고, 학습을 마친 모델들이 같은 문제에 뭐라고 답했는지 비교해 보자.

문제는 시험 세트 앞쪽에서 규칙대로 골랐고, 모델 점수는 보지 않았다. 점 세 개는 초기화 난수만 다른 모델 세 개의 답이다. 여기 나온 8문제는 표본이라, 전체 시험 정확도는 오른쪽 숫자를 보면 된다.

움직임은 원리를 보여 주는 그림이고, 학습된 값은 아니다. 비교 대상인 GRU는 상태 하나를 통째로 고치는 가장 단순한 순환 신경망이다. 새 구조라면 적어도 이걸 넘어야 한다.

오래 가르치면 순위가 바뀐다

800걸음에서는 다들 고만고만했다. 3000걸음까지 늘리니 Transformer가 치고 나갔다. 굵은 선이 3000걸음, 옅은 선이 800걸음이다.

학습 때보다 긴 사슬

사실을 섞어 보여 주고 끝까지 따라가게 하는 문제다. 학습에서는 3단계까지만 봤다. 점선 50%는 끝 개체 둘 중 아무거나 찍은 점수다.

64기호 밖을 기억할 수 있나

키 두 개를 저장하고 한참 뒤에 묻는다. 오른쪽으로 갈수록 오래전에 저장한 값이다. 청크는 학습 신호가 거슬러 올라가는 길이다.

새 과제 다섯: 어디서 무너지나

난이도를 올려 가며 봤다. 세로선 오른쪽은 학습 때보다 어렵게 낸 시험이다. 순환 사슬은 아무도 못 풀었고, 느린 주기는 Transformer만 풀었다.

과제별 전체 정확도 보기

고쳐 봤더니

약점을 고친 개선판을 같은 조건으로 돌렸다. 빈 원이 원래 모델, 찬 원이 개선판이다. 오른쪽으로 가면 나아진 것이다.

뭘 고쳤나
  • Folio2 (파라미터 –): 기호마다 꼭 어딘가에 쓰던 걸 쓰지 않아도 되게 했고, 칸을 내용으로도 찾게 했다.
  • Lattice2 (파라미터 –): 입력을 모든 칸에 넣고, 이웃 메시지를 정규화했다.
  • Strata는 개선판을 만들지 않았다. 층마다 다른 속도라는 가설부터 느린 주기 과제로 시험했다.

핵심 장치를 빼 봤더니

빼서 점수가 떨어지면 그 장치가 실제로 일을 한다는 뜻이다. 세로선이 원래 모델, 빈 원이 뺀 모델이다. 전부 800걸음 기준이다.

대신 느리다

파라미터 수는 비슷해도 계산 비용은 크게 다르다. 후보들은 기호마다 작은 GPU 연산을 여러 번 부른다.

측정값 전체 보기

한 모델씩 일반 방식으로 쟀다. 실제 실험은 난수 3개를 묶어 CUDA graph로 돌려서 후보 학습이 5–30배 빨랐다. 결과는 같다. Transformer 지연은 KV 캐시 없이 창을 매번 다시 계산한 값이다.

아직 모르는 것

  • 학습률을 모델마다 찾지 않았다. 전부 2e-3이다. Lattice가 들쭉날쭉한 것도 학습률 탓일 수 있다.
  • 같은 걸음 수로만 비교했다. 같은 시간으로 맞추면 후보들은 훨씬 덜 배운다.
  • 난수가 3개뿐이다. 셈 나머지처럼 난수에 따라 둘로 갈리는 과제는 평균을 믿기 어렵다.
  • 관계 사슬 시험에 지름길이 남아 있다. 50% 근처 점수는 끝 개체를 찍은 것일 수 있다.
  • 개선판의 고침을 따로 떼어 보지 않았다. 고친 것 중 어느 쪽이 효과인지 모른다.

다음에 할 것

  • 모델별로 학습률을 몇 개 골라 3000걸음 비교를 다시 낸다.
  • Lattice2의 반복 수와 칸 수를 바꿔 본다. 깊은 괄호에서 왜 떨어지는지도 본다.
  • Strata의 느린 층이 진짜 느린 정보를 잡게 할 방법을 시험한다.
